Keep root `Project.md` authoritative for verified current state and navigation. Create design-specific procedures in `Project/skills/` and supporting context in `Project/Context/`; add their links to `Project.md`. This permission covers useful local resources, not unrelated actions or overriding design intent. Shared template guides/skills remain reusable product files.

Use the [workspace procedure](references/workspace.md) for creating/indexing resources and native discovery registration, or the [updater guide](../../../.updater/README.md) for template updates. Read only relevant context/skills through the project index. Never auto-import every project reference or modify an existing project's unregistered skills just to match this layout.
